## 口径

- 流失定义：末次购买后连续 **30 天**无购买（依据见 `spec.md` 第 4 节）
- 观察终点：2011-12-09
- 右删失：观察结束时仍未达到 30 天空窗，`E = 0`
- 入组：只保留首次出现不早于 2010-05-30（数据起点 + 180 天回看期）的用户，剔除 2,702 人。更早首次出现的用户无法确认此前没买过，大多是老客户，见 `reports/left_truncation.md`

## `T = 0` 的处理（重要决策）

原始算式 `T = L - F` 会让 **1,287 个首末购买同日的用户（40.5%）得到 `T = 0`**。

`T = 0` 在生存分析里没有「存活时长」的含义。改为 inclusive 计日后，这 1,287 人分成两组：

- **1,159 人**（36.49%）在主口径下是 **t=1 事件**，KM 曲线在 t=1 处从 100% 降到约 **63.5%**
- **128 人**是删失，`T` 远大于 1，不会在起点造成台阶

**处理方案**：改为 inclusive 计日 `T = 天数差 + 1`，首末同日记 **1 天**。

- 处理后 `T` 最小为 1，无 0 或负数
- 代价：所有时间点整体右移 1 天，相对比较不受影响
- 选择这个方案而不是「+1 天」或「剔除」：剔除会丢掉流失最快的那批人，造成选择偏差；单独给 0 值补 1 又破坏了口径统一

## 已知问题（写报告时必须交代）

1. **事件率 72.13% 偏高**：行业常见的预测场景是 10%–30%。根因是一次性客户占比高（40.5% 的用户只在一个自然日内购买过），不是口径造成的。
2. **未剥离季节性**：末次购买高度集中在 11–12 月旺季。
3. **无真实标签**：「流失」是业务假设，不是数据标注的事实。
4. **观察终点截断**：2011-12-09 之后无数据，靠近终点的用户无法确认「永不再来」。
5. **人群混有回流客户**：180 天回看期只保证入组前半年无购买，沉睡更久后回来的老客户仍在其中。
